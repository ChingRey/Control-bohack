# Control Teaching Engine 接口交接摘要 V0.2.1

**这次交付的两项新增约定：**

1. `teach()` 的策略选择由**教学智能模块**执行。基础流程组提供授权候选列表、已分配策略与显式切换权限，并保存/验证返回结果；不自行制定选择算法。
2. `teach()` 每轮接收**真正执行过的教学动作、学生回复和评价反馈摘要**，支持连续教学策略调整，不能拿模型预想步骤冒充历史记录。

**新字段：**

- `TeachRequest.strategy_candidates`：至少一项完整 `TeachingStrategy`。
- `TeachRequest.active_strategy`：首轮 `null`，后续必须是后端已保存 `{id,version}`。
- `TeachRequest.allow_strategy_switch`：仅可信后端控制。
- `TeachRequest.teaching_history`：历史回合 + 历史评价 + 截断标志。
- `TeachingTurn.strategy_selection_mode`：`initial/continued/switched`。
- `TeachingTurn.strategy_selection_reason`：选择或切换理由。

**版本升级：** 原 V0.2.0 `TeachRequest.strategy` 已被替换，四接口的 `schema_version` 都改为 `0.2.1`，必须按 `MIGRATION_V0.2_TO_V0.2.1.md` 升级。网站旧 `schema_version=1` 协议必须保留，独立适配。

**基础组现在做的事：** 接入四个 Mock、映射真实 Coding 证据、记录多轮教学和策略分配、完成 HTTP/状态机/暂停恢复/浏览器/Windows 测试与真实仓库部署工作。详见 `基础流程组_接入与部署清单.md`。

**注意：** 本包的可执行测试只验证合同与模拟调用；课程 Rubric 尚未正式确认，部署、网站集成、真实模型与教学效果仍未验收。
