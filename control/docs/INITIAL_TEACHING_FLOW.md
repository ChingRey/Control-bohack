# 初版教学流程与后续策略优化边界

当前策略版本initial-v1：点明问题（不展开原因）→讲解知识与原理、解释为什么→回到同一个问题，联系真实位置并帮助学生应用。

提示词位于agents/teaching_assets/strategies/initial-v1.json，由agents/teaching_strategy.py读取。课卡与教学阶段方法沿用main；它们决定内容和阶段目标，版本化策略决定如何讲。没有代码错误时围绕理解缺口或学习目标，不捏造错误。后续追问沿记忆接续，不强制每条消息重复三段。Teacher仍不写代码、不替学生验收。

## 后续可替换的部分

策略步骤、步骤指令和讲解方式独立存放。后续优化组登记新版本后，通过task.teaching.strategy_version选择，原版本不覆盖；evolve接口仍保留候选策略入口，不自动晋升策略。不训练或切换底层模型，不修改Coding执行控制。

## 提供给评价/优化组的数据

每个Teaching turn记录策略id/version、期望步骤、输入消息编号、回复消息编号、代码版本及已有课卡来源；完整回复、后续学生回答和Coding交互继续保存在原始消息记录。reply_message_id对应成功回复随后写入的位置；整轮失败或过期不提交策略成功记录。

策略定义里evaluation_contract预留观察维度：具体问题、原理因果、是否回到同一问题和真实证据，以及学生能否解释原因、提出修改指令、迁移验证。adherence_verified和learning_effect_verified均为false，不把加载提示词、格式齐全或模型自称有效当作通过。评分标准、帮助程度标注、独立考核和策略比较由优化组后续实现；不能把代码Agent产出的正确代码直接算成学生学会。

## 当前限制

这是可替换的初版教学提示词，不是教学效果已验证的系统。教学大阶段仍由现有workflow管理，独立于Coding计划；没有以Coding步数自动判定学生掌握。模型请求仍可能超时，输入减小或流程明确不保证服务商响应速度，流式输出本轮尚未实现。
