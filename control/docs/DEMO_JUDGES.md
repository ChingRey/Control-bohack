# 评委演示与回退

在首页打开「跨用户策略进化」，在「查看记录」选「自动模拟」。选择考核案例、模拟条件、首次参与人数和回访轮数，再点「开始自动模拟」。两个案例都支持自动答题。默认 50 人加 5 次回访，人数可在 1～200 内调整。页面显示已完成轮数、当前学生和阶段、最近完成的轮次，完成后展示该案例的结果。每批使用独立 SQLite；5 组可比配对是自动模拟的晋升门槛，样本不足时保留试用状态。

## 现场讲法

1. **即时反馈一：先决定教什么。** 在「单次教学试验」提交前测。主机开启 CONTROL_ALLOW_SIMULATION=1 时，可用「新建手工模拟」自行作答。Evaluate 按量表找薄弱项，Decide 把薄弱项变成本轮目标，例如先练习验证纯空格是否真的被拒绝。展开目标依据可对上评价和决策。
2. **即时反馈二：再决定怎么补。** 在练习中保留纯空格判断错误。Evaluate 提交练习反馈，Teach 以同一教学目标为准，插入逐项记录「输入 → 预期 → 实际」的补练。展开可看到触发补练的评价。
3. **长期进化：让后面的人试用。** v1 指本案例的初始教法，先运行再核对记录。v2 是根据前人评价提出的候选，只替换引导练习。新用户实际试用后，Evolve 依据配对结果决定是否晋升。通过后，相同条件的新用户才会使用；在「按参与者回看」可以看到该用户当时是基线、试用还是验证后采用，以及回访记录。
4. **指标要解释分母。** 前测和后测使用同一四维百分制，增益是后测减前测。判断时要求平均增益比基线至少多 5 分且后测均分提高，迁移等级提高，迁移通过、行为检查和提示负担不得变差。模拟需要 5 组配对，真人试点需要 2 组，每组前测差不超过 10 分。独立迁移单独按 0–4 级看新场景的应用。展开「评分基准」可看五维权重，展开对照可看规则和证据。

顶栏「连接模型」用于本地配置 Coding 与 Teaching。局域网演示由主机通过「配置模型.cmd」统一配置。设置保留界面偏好及模型超时。课卡、学习路线、验证与交付属于项目教学支撑，入口移到「项目工具」。项目教学复盘位于首页独立入口，提供当前项目反思、证据和局部候选。现有复盘使用模型观察，对当前项目适用。两次即时反馈和跨用户策略需要各自的实际评价和试用证据。V0.2.1 联调界面已移出用户页面，默认服务也不提供联调端口。测试可在本机用 CONTROL_ENABLE_DEV_INTEGRATION=1 显式启用受保护的旧接口。

## 回退给负责人操作

- **候选还在试用，验证未通过。** 后端记录 rejected，后续不再选择这个候选。默认教学仍沿用原策略。失败配对留在记录中。
- **已晋升的策略需要撤回。** 在服务主机进入 control 目录。指定当前服务所用的数据目录，运行下方命令。记录策略版本的撤回原因，并让匹配的新会话回到上一个可用祖先版本。若祖先只有 v1，便回到基线。源策略、试验、评价和已开始会话的现场记录继续可查，其后继候选也一起退出调度。回退作用范围是该策略的匹配条件。以后新的候选达到验证门槛，才会解除这条回退指定。

```powershell
# 真人工作台，若之前用自定义目录启动，先设置相同的数据目录
python -X utf8 scripts/rollback_teaching_strategy.py --cohort human --version 2 --reason "复核发现迁移效果下降"

# 验证模拟回退。目录名来自 data/workbench/strategy-simulations/latest.json 的 id
$baseData = (Resolve-Path '.\data\workbench').Path
$runId = (Get-Content -Raw (Join-Path $baseData 'strategy-simulations/latest.json') | ConvertFrom-Json).id
$env:CONTROL_WORKBENCH_DATA = Join-Path $baseData ('strategy-simulations/' + $runId)
python -X utf8 scripts/rollback_teaching_strategy.py --cohort simulation --version 2 --reason "演示撤回"
Remove-Item Env:CONTROL_WORKBENCH_DATA
```

回退动作仅通过主机命令操作，页面展示当前策略状态、证据和历史使用情况。两次即时反馈的完整可追溯链目前覆盖「待办输入边界」试验。普通项目照常使用项目内教学与复盘。现有自动模拟的答卷由程序生成，验证状态迁移和复用，真人教学收益需要真人试验。
