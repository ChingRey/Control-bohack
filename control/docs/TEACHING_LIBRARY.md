# 已筛选教学资料的运行时接入

版本：teaching-20261114-v1。31条可参考来源、21张原创课卡；不是31套课程全部阅读或教学效果证明。原始研究与阅读局限见research/teaching-20261114。动态入口、旧课程和研究摘要未直接作为可执行指令导入。

## 实际调用链

后台保存学生原话 → Teaching读取当前项目快照 → 教学阶段方法及资料选择 → project_chat真实提供商请求 → 只读源码/历史工具 → 回复与资料轨迹保存 → 可选后台材料整理。

agents/teaching_library.py从固定离线JSON读取筛选资料，校验内容哈希。优先当前已进入执行的学生问题和明确选学主题，再参考当前阶段或完成检查点；排队消息不提前参与选择。课卡含概念说明、不同场景例子和具体检查要点，而不只是题目；最多两张课卡、六条课卡来源，新增JSON最多11000字符且受现有上下文剩余预算约束。教材例子不得冒充当前源码或真实操作结果。

通用指导强调根据知识缺口调整帮助、减少无效反问、讲解后回到真实作品、区分风格与错误、分开任务成功与理解。必要时先解释术语或给另一个小例子；已有理解则减少提示。不设置新的教学关卡，不自动给分或解锁。

## 学生入口与来源回查

真实项目左侧“项目技术 · 自由选学”显示按需建议及全部21个主题，可选择了解、稍后或回到自动建议。自由开发不自动安排阶段课；学生明确提出问题或选择主题时仍可提供对应资料。稍后偏好持久化，旧问题不会立即重开被暂缓的课；学生日后主动重提或选择可重新学习。

POST /api/tasks/:id/teaching/resources：{lesson_id,choice:"learn"/"later"}；choice:"auto"清除指定主题。learn先保存学生请求，再启动只读Teaching返回202；later/auto保存偏好返回200。快照teaching_library包含主题列表、建议、偏好、最近完成轮次的资料轨迹和出处。health.teaching_library提供版本与数量。

最近教学参考展示实际保存的来源标题/URL和资料版本，并区分真实模型提交与sample未提交。轨迹保存课卡版本、来源快照和内容哈希，避免后续目录改版让旧来源无法回查。submitted_to_model只证明已送入本轮请求，不证明模型采用或学生掌握；sample始终为false。

## 与经验、画像及权限的关系

后台整理器可接收本轮资料轨迹和整理约束，但外部来源不能作为evidence_ids或quotes；原话引用校验不变。课卡已加载不等于讲过、练过或掌握。新增建议保留资料方法出处，仍需要既有审核。教师不会自动写入已确认项目规则或永久画像。

Teaching工具仍只有read_project_file和read_message_history。Coding文件能力、检查点恢复幂等、锁与过期校验、900秒上限均未改变。运行时不从网页下载脚本、不全局安装Skills。

## 验收

test_teaching_library.py覆盖完整性、按问题选择、排队隔离、稍后/自由模式、预算、真实适配器请求注入（模拟提供商响应）、来源保存与sample标记、外部来源不得冒充学生证据、选学API及权限不变。

verify_workflow_browser.py在临时数据库和独立真实浏览器中检查21个主题、选择存储课卡、来源链接和未提交模型标记，并继续覆盖原有开发/回退/交付流程。没有用真实账户模型效果冒充这些接口测试。

本轮实际结果：159项测试通过（开启真实浏览器用例）；真实工作台页面的选学与出处、功能接受、恢复和交付验收通过。提供商响应使用sample/mock，不代表实际账户模型教学效果。记录见experiments/teaching-library-20261114.json。
