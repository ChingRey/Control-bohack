# 从需求到交付的本地流程（2026-11-14）

本轮在 main@0d8373b 上实现本地端到端流程。Coding 自主使用原生项目文件工具，支持任意项目内文件类型和二进制，执行超时仍900秒，不设置逐文件审批。Teaching 的工具仍只有 read_project_file 和 read_message_history；它不能写源码、发Coding执行指令或自行恢复开发。独立后台整理器使用已配置Teaching提供商提炼待审核材料，不赋予Teaching源码写权限。

## 原始0—11步对应实现

| 步骤 | 当前入口与行为 |
|---|---|
| 0 初始化 | 三份共享材料与两份教师记录；概念从unknown开始；提供保留无关文件、如实报告验证两条基础规则。学习者身份和跨项目经验需明确选择。 |
| 1 收窄需求 | Teaching自然交流、requirement-scoping；后台整理器从带编号原话产生需求草稿，学生可修改确认。 |
| 2 快速原型 | “按已确认需求生成原型”直接启动Coding，无需完整开发计划；工具写入后发送完成检查点。1分钟是目标，不作时限保证。 |
| 3 看懂作品 | concept-walkthrough结合真实带行号代码；讲解/练习/独立表现候选分开，覆盖记录需复核，不认证掌握。 |
| 4 条件与数据设计 | 设计单草稿/确认/版本历史；设计决定保存在设计单，不冒充验证过的经验。 |
| 5 单个功能 | 建立/选择当前功能，单独于开发计划step；Coding接收确认材料、最新草稿、已审核规则及当前功能。记录实际提交的材料/规则版本。 |
| 6 审查本轮变化 | Diff查看和Teaching审查；代码含网络调用或疑似凭据时附加safety-guard；规则遵守观察绑定来源且只作待核实建议。 |
| 7 测试与修复 | 人工操作/预期/实际/结果绑定文本+二进制联合哈希；独立Edge/Chrome步骤验证；Python unittest或Node --test在副本执行。所有写文件前自动保护版本。 |
| 8 回归与恢复 | 保留/改变/回归说明；当前版本有验证记录后可接受功能。版本恢复前再次保护当前代码，不回退聊天与学习记录。 |
| 9 复盘经验 | 真实整理器产生引用原话的规则候选；显示近似旧项并允许指定修订目标；旧版不覆盖，有效规则最多15条，支持停用。5—9可反复循环。 |
| 10 外部能力与安全 | 静态凭据信号及网络超时/错误处理提示；输入/权限由教师结合项目判断。源码只读Teaching给修复建议，由学生发送给Coding。Python/Node服务可在副本显式启动/停止，PORT指定独立端口。 |
| 11 结项与留存 | 学生填写如何运行/实际测试/限制，最终版本保护；交付ZIP含项目、运行README、HANDOFF、分类证据和静态启动脚本；排除.env、依赖缓存等。经确认将通用规则及可选教学观察留存至所选学习者，另一项目须明确载入。 |

## 交互与状态保证

- 两侧聊天无论忙闲都先保存，request_id重放不重复写消息；同任务串行排队。未处理队列不进入当前执行上下文，也不使当前候选代码过期。刷新不丢队列；重启后需要显式重试，不自动重放代码操作。
- 模型失败仍保留用户消息，失败消息有重试入口。后台工作各有run状态；过期结果不整块覆盖任务。未保存编辑器内容不会被聊天轮询清除。
- 三份共享材料与教师私有记录分离。Coding不接收学习者观察；个人通用经验按本机身份显式载入，模型观察和人工确认都不是掌握证明。
- 草稿、确认材料、规则版本、规则停用、代码版本、测试与模型建议分开。词项近似只是查重提示，语义修订由模型建议和学生复核；不把旧规则被违反直接归因为规则模糊。
- 教师六类方法是本应用提示材料，按阶段预载并记录使用名称；参考先前Skill审查的需求澄清、排错、验证与测试规划原则，不等同全局安装65项Skill，不运行第三方脚本，不宣称效果提升。Coding原生Skill安装/能力评估仍是独立实验，旧skill_gateway保持未启用回执。

## 运行和交付边界

本地服务支持Python或Node入口，入口需读取PORT并绑定127.0.0.1；未自动安装依赖。它执行学生项目代码，使用副本与不含提供商密钥的环境，但不是操作系统安全沙箱。浏览器验证使用独立资料目录和项目副本，默认阻断外部网络；只证明列出的断言，不代替真实外部API/账户验收。至少有一个断言才允许浏览器测试，零测试不能标通过。

安全扫描只给静态信号，不宣称项目安全；疑似密钥阻止生成交付包，聊天、修改和修复仍可进行。模型输入与输出日志对已识别凭据脱敏，原项目源码不被脱敏逻辑改写。

本轮提供可部署交付包与本地运行，没有替用户选择公网平台或发布私人项目。实际公网发布还需确定目标平台、账户权限、运行环境及域名；这是外部部署配置，不是当前本地流程的代码开关。

代码版本当前仍随任务持久化，长项目的存储去重/分页和多进程协同尚未作为生产规模能力验收。
