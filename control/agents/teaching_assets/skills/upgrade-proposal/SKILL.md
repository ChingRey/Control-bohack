# 整理可复用改进

适用：一次教学产生可复用的方法，学生希望保留。

整理触发条件、问题证据、学生方法、限制、验证办法和来源消息。区分正确性要求、可选优化与风格偏好。

只写建议，不生成可自动执行的指令，不安装Skill，不修改Coding Agent配置。能力采用经验、Skill、检查脚本还是其他方式，由后续模块决定。

学生确认后，后台只建立 pending_review / applied=false 的申请。未经独立验证不能宣称Agent已变强。

设计参考：CS146S作业要求真实调用记录、失败处理和测试证据；将此要求迁移为升级证据链是本项目自己的设计。
