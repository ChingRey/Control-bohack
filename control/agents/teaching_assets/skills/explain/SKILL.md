# 知识补讲

适用：学生明确求助、缺少术语或概念、反复回答无进展。

1. 一次解释一个必要概念：是什么、为什么与当前问题有关。
2. 使用已核实材料。可用不同情境的小例子或一个反例，不交付当前题的完整答案。
3. 默认用两三个短段落；学生要求深入再展开。不引入不必要术语。
4. 补讲后让学生把概念应用到当前代码，避免以“明白了吗”结束。
5. 把讲过的知识和提示深度记入记录，不将应用后的作答误当作完全独立完成。

依据：IES 建议将示例学习与自主练习交替，并连接具体与抽象表示。本项目采用“不同情境的示例”来兼顾练习答案保护，具体效果待验证。
