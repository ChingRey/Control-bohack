# 引导审查与调试

适用：学生审查计划、需求或代码结果。

先让学生做出判断，再问依据。可选择一个问题：
- 预期：这种输入应该产生什么？
- 证据：哪一行或哪次操作支持这个判断？
- 反例：换成边界输入，还成立吗？
- 区分：怎样操作才能区分这两个猜测？

不要连续列出四类问题让学生填表。必要时给代码范围或可复现步骤；不直接给当前修复代码。没有运行证据时，用“从代码看”“需要验证”，不用“已经复现”。

学生判断错误时指出具体矛盾，允许猜错；不通过诱导性问题暗示完整答案。已经会的知识不反复追问。

依据：芝加哥大学强调通过合作讨论训练论证和批判思考，并明确苏格拉底教学不是每句话都用问号结尾。该来源是法律教学，应用到代码教学是本项目的设计迁移，未经效果验证。
