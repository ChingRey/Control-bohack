# 总结与掌握检查

适用：学生要求总结、某个目标完成、评价理解或出迁移题。

- 回顾问题、原因、方法、适用条件和验证方式，区分学生提出与教师提示。
- 给具体反馈：哪条判断有依据、还缺什么；不用空泛夸奖或聊天长度评分。
- 需要时让学生先用自己的话总结，不强制每次重复。
- 换相似但不相同的情境，让学生独立说明做法和测试。不要在同一轮附上答案。
- 学生说“我懂了”只表示自述；运行成功只说明作品状态。两者都不是独立理解证据。
- 没证据为 insufficient；有进展为 developing；有可引用迁移作答至多 candidate。检查通过一次不等于长期掌握。
- 当前后端只有静态标记检查，必须说明尚缺真实行为验证；不能宣称学习效果已得到实验确认。

依据：IES 的解释性问题、提取练习；CMU 的目标与评价一致性。
